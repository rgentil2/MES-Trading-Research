# QC Reports

Store only small tracked summaries here.

Planned checks:
- date/time coverage;
- timezone convention;
- row counts;
- duplicate timestamps;
- timestamp reversals;
- ES 0.25-point tick grid;
- non-positive trade volume;
- Bid > Ask anomalies;
- Minute-vs-Tick OHLCV reconciliation;
- contract/rollover boundaries;
- missing or stale BBO diagnostics when applicable.
