# Research

- `active/`: experimentos actuales del programa histórico MES.
- `archive/`: experimentos cerrados; no se borran del historial científico.
- `candidates/`: candidatos históricos.
- `es/`: **nuevo programa principal de investigación ES**.
- `experiment_registry.csv`: historial maestro.

Cada experimento debe pre-registrar pregunta, hipótesis, dataset, ventana de entrada <= 11:30 ET, métricas y gate antes de ejecutar.

Para ES: **2020–2024 desarrollo, 2025 validación y 2026 pseudo-forward final**. Descargar o almacenar holdouts no autoriza su análisis.
